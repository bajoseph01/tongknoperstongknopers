# Afrikaanse Tongknopers

A single-file classroom web page for practising Afrikaans tongue twisters with Grade 4–6 FAL learners.

## Features

- Notebook-doodle classroom design
- Level tabs: Maklik, Gemiddeld, Uitdaging
- Cards start blurred for prediction/reveal practice
- First click reveals the Afrikaans tongknoper
- Further clicks toggle Afrikaans ↔ English
- Random class challenge button
- Print-friendly layout

## Use

Open `index.html` in a browser, or publish the repository with GitHub Pages from the `main` branch root.
